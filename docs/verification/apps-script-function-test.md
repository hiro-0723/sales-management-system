# Apps Script関数確認手順

## 1. 事前確認

- 対象ファイルと関数名
- 実行するApps Scriptプロジェクト
- 読み取りだけか、データを変更するか
- 正常条件と異常条件
- 確認用データ、事前値、復元方法
- 実行許可

## 2. ローカル確認

```bash
node --check 対象ファイル.js
git diff --check
git diff -- 対象ファイル.js
```

Apps Script固有APIの正常性は`node --check`だけで確定しない。

## 3. 反映

対象、差分、復元方法を確認し、許可後に`clasp push`を実行する。対象プロジェクトが正しいことを`.clasp.json`とApps Script画面で照合する。

## 4. 実行確認

1. Apps Scriptで対象ファイルと関数名を確認する。
2. 対象関数だけを実行する。
3. 実行ログとエラーを確認する。
4. 変更対象のシート、フォーム、プロパティ、トリガーを確認する。
5. 同じ操作を再実行した場合の重複や破壊がないか確認する。
6. 確認用データを復元し、再読込後に復元を確認する。

## 5. 報告

- ファイル名・関数名
- 対象環境
- 実行結果とログ
- 正常条件との照合
- 変更されたデータ
- 復元結果
- 未確認事項
