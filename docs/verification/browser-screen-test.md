# 画面確認手順

## 1. 対象

Googleフォーム、Google Sheets上のダッシュボード、将来のLINE WORKS操作画面など、利用者が操作・閲覧する画面に使う。

## 2. 事前確認

- 対象画面と環境
- 利用者の役割と権限
- 今回確認する1目的
- 正常条件と異常条件
- 保存されるデータと復元方法
- 実データを変更する場合の許可

## 3. 確認

1. 初期表示、説明、入力項目、選択肢を確認する。
2. 正常入力を行い、送信・保存・画面応答を確認する。
3. 必須不足、形式不正、重複、再送など必要な異常経路を確認する。
4. 保存先のID、状態、関連データを確認する。
5. 再読込または再表示後も結果が正しいことを確認する。
6. 必要な画面・ログ・画像を根拠として残す。
7. 確認用データを復元し、再読込後に復元を確認する。

## 4. LINE WORKS

LINE WORKS固有の操作、認証、Webhook、返信、エラー表示は未確定である。公式仕様とテスト環境で確認方法が確立した後、この手順または専用手順へ追記する。

## 5. 報告

- 対象画面・利用者役割
- 実施操作
- 正常・異常条件との照合
- 保存先の確認
- 根拠
- 復元結果
- 未確認事項
